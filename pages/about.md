# About

Athy (short for *Automated Hydroponics*) was a side project from 2019 to 2023. It started as an ESP32 and Raspberry Pi hydroponics platform written in .NET, and this code generator grew out of it. The code lives in the [athy-org](https://github.com/athy-org) GitHub org, and the full story is in [this post](https://buildingthingswith.net/athy-labs/).

These days the work sits under [Lilly Labs](https://lillylabs.co.za).
