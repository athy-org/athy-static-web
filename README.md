# athy-static-web

Landing page for the Athy .NET code generator, live at <https://athy-generator.lillylabs.co.za>.

This is an archived showcase. The generator was built 2020 to 2023, before ChatGPT and AI coding assistants were part of everyday development. The site used to live at generator.athylabs.com, later generator.athylabs.co.za, until those domains lapsed. It is a Jekyll site deployed to GitHub Pages by `.github/workflows/pages.yml`.

Background: [Athy Labs: automated hydroponics and a code generator](https://buildingthingswith.net/athy-labs/).
